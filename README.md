## 🚕 Flagship Project — E-RANK
**South Africa’s Digital Taxi Rank Platform**  
Digitizing operations across the minibus taxi industry with a five-role architecture:

- 👑 **Admin** — System Control  
- 🏢 **Owner** — Fleet Management  
- 🛡️ **Marshal** — Rank Operations  
- 🚗 **Driver** — Trips & Vehicles  
- 🧍 **Passenger** — Journeys  

**Core Features:**
- Live taxi queues & GPS geofencing  
- QR rank check-ins  
- Digital manifests & next-of-kin details  
- SOS alerts & journey sharing  
- Role-based permissions & credential protection  

**Tech Stack:** React · Tailwind · shadcn/ui · FastAPI (Python) · MongoDB Atlas · JWT · Google Maps · Web Speech API · Render Deployment
